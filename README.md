# ECE128Lab1Code

This repository contain Verilog code for the design of an 8 to 1 mux. It is meant for lab 1 for ECE128. It is written in three styles of Verilog (Structural, Behavioral, Data Flow) along with a test bench. 

Instructions:
1. Create project in Vivaldo using correct FPGA selected
2. Move Mux code into source file
3. Assign inputs to switches on FPGA and outputs to LEDs usings provided file
4. Add constraint to add test bench in
5. Run Simulation to check wave form (Test bench should show alternating pattern of 1 and 0)
6. Run synthesis and check resulting gate level results
7. Create bit stream
8. Program FPGA
9. Test FPGA if all test cases work
